FERNWOOD BOOKS — MOBILE FIX

IMPORTANT: Upload the CONTENTS of this folder to the GitHub Pages publishing root
(the same folder that contains index.html), not the enclosing ZIP folder.

The published structure should look like:
  index.html
  about.html
  contact.html
  css/reset.css
  css/nav.css
  css/style.css
  js/nav.js
  js/contact.js

Do not place these files inside an extra fernwood-books/ folder unless your
GitHub Pages site is configured to publish from that folder.

After uploading, open the site in Chrome and refresh without cache, or clear
the site's cached files. Check that /freewood/css/nav.css and
/freewood/css/style.css load in the browser.
